# Code-Live

Code-Live is a simple live coding platform built using **Node.js**, **Express**, and **EJS**.

## 🚀 Features
- Live code editor interface  
- Server-side rendering with EJS  
- Express-based backend

## 🛠️ Requirements
- Node.js (v14 or higher)
- npm
- (Optional) MongoDB, if required by the project

## ⚙️ Setup (Windows / macOS / Linux)

```bash
git clone https://github.com/Harshit9670/Code-Live.git
cd Code-Live
npm install
npm start
